# Prévia de Storyboard

Plugin API v2 para a etapa de Edição. Recebe planos normalizados, composições animadas produzidas pelo Compositor de Animação de Storyboard e áudio MP3. Valida um programa visual por cena e entrega um manifesto de prévia (`text/one/inline`) para o player do ContentFlow. O player desenha primitivas vetoriais, transições e movimentos no tempo da narração; permite reproduzir, pausar e buscar, sem usar os SVGs de planejamento, gerar MP4 ou publicar conteúdo.

O Método pode vincular cada porta a uma entrega específica de um Processo anterior. O plugin não acessa arquivos, rede ou sessão de navegador.
