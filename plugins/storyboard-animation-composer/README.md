# Compositor de Animação de Storyboard

Plugin API v2 de Edição. Recebe os planos visuais normalizados pela etapa de Assets e transforma o desenho planejado em um programa vetorial animado por cena. Usa entradas e movimentos variados conforme a relação editorial e preserva a identidade, ordem e tempos fornecidos pelo Core. Não desenha o cartão de planejamento nem gera vídeo. A prévia final é reproduzida pelo plugin `com.contentflow.storyboard-preview` e pelo player do ContentFlow.
